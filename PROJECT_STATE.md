## WHAT HAS BEEN DESIGNED (Complete Vision)

RÉSONANCE is a cooperative cultural infrastructure
for independent French artists. It is both:
- A web agency product (you build sites for artists)
- A SaaS platform (artists self-serve)

### The Platform Has Six Sides
1. Artists — pay subscription, get complete platform
2. Fans — free, discover, buy, fund (Atelier access)
3. Venues — pay listing, fill empty dates
4. Studios/Rehearsal spaces — pay listing
5. Amplificateurs — influencers, free/paid
6. Talents — art management students/graduates

### Five Modules Designed
```
/onboarding — AI-guided self-setup wizard
/website    — bilingual site, CMS, Atelier fan area
/content    — social media engine, repurpose content
/concerts   — event management, feuille de route
/legal      — GUSO, CDDU, intermittent (killer feature)
```

### Key Features Designed (North Star)
- Interactive Feuille de Route (live checklist, not PDF)
- What-If Concert Budget Simulator (venue comparison)
- Co-Events (multi-artist shared concerts)
- Content Studio (upload once → posts everywhere)
- AI Data Importer (scrape legacy URLs → Sanity)
- Billing Providers (for non-incorporated artists)
- Open Data venue database (Paris + national)
- Fanbase graph (cross-artist fan intelligence)
- Crowdfunding Phase 2A (external links, no money handling)
- Crowdfunding Phase 2B (Stripe Connect, later)
- Professional marketplace (Phase 2+)
- SASU + cooperative international structure
- SEO strategy (schema.org, hreflang, content guides)
- Full resilience architecture (graceful degradation)
- Three-level monitoring (technical/business/behavioral)
- Subdomain mode: concerts.artistname.com (wedge entry)
